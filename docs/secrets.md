# Секреты и chezmoi

Правило по умолчанию: **в этом репозитории нет секретов**. Только конфиги,
которые не страшно увидеть публично.

## Если конфиг всё же требует секрет

Например, в `.zshrc` нужен API-токен, или в конфиге программы — пароль.
chezmoi умеет подставлять такие значения из внешнего источника прямо при
`apply`, не храня сам секрет в git.

1. Файл превращается в шаблон: переименовывается в `dot_zshrc.tmpl`
   (суффикс `.tmpl` говорит chezmoi, что внутри есть Go-шаблоны).
2. В нужном месте пишешь:
   ```
   export MY_API_TOKEN="{{ (bitwardenFields "item" "my-token").password.value }}"
   ```
   (пример для Bitwarden CLI; аналогично работает с `pass`, 1Password,
   `gopass`, командой `keyring` и т.д. — chezmoi поддерживает несколько
   бэкендов, см. https://www.chezmoi.io/user-guide/password-managers/)
3. При `chezmoi apply` значение подтянется из пароль-менеджера в момент
   применения и запишется в реальный `~/.zshrc` на диске — но НЕ в git.

## Простое правило

Если сомневаешься, класть ли файл в chezmoi — спроси себя:
"Ок ли, если этот репозиторий вдруг станет публичным?"
Если нет — это либо не кладётся вообще, либо кладётся как `.tmpl` с
подстановкой секрета из пароль-менеджера, а не как открытый текст.
