# Если решил убрать программу совсем (не только конфиг)

`run_once_*` скрипт выполняется только один раз на машину, поэтому просто
удалить строку из `packages/apt.txt` НЕ удалит уже установленный пакет.

Если хочешь убрать программу с уже настроенной машины:

```bash
sudo apt remove --purge <имя-пакета>
```

и убери саму строку из `packages/apt.txt`, чтобы на новых машинах пакет
больше не ставился.
